## 三、历史视角：技术革命与金融革命的“双螺旋”

### 3.1 一个核心命题：技术突破需要金融“翻译”为产业变革

英国是第一次工业革命的发源地。但一个耐人寻味的事实是：**蒸汽机技术在工业革命爆发前几十年就已经成熟了**。第一台实用蒸汽机由纽科门于1712年发明，但直到1760年代瓦特的改良版本才开始真正改变世界——中间的几十年，技术一直在等待金融体系的成熟。

1694年，世界上首家中央银行——**英格兰银行**创立。1773年，伦敦证券交易所建立。正是这些金融制度的创新，将英国农村地区的储蓄转化为工业资本，让工厂能够买得起蒸汽机。

**技术视角的延伸**：注意，这不是说技术本身停滞了——瓦特的改良本身就是技术进步。但如果没有资本将实验室里的原型转化为工厂里的机器，技术就只是技术，而不是“工业革命”。**技术创造了可能性，金融实现了可能性**——这就是我们理解科技-金融关系的基本框架。

### 3.2 第一次与第二次工业革命：银行体系与大规模资本

#### 【核心技术演进】

- **第一次工业革命（1760s—1840s）** ：蒸汽机、机械纺织、焦炉冶铁 → 人类进入“机器时代”
- **第二次工业革命（1870s—1910s）** ：电力、内燃机、化学工业 → 人类进入“电气时代”

#### 【技术成本视角】

一台瓦特改良蒸汽机成本约**2000英镑**，是当时英国男性年收入中位数的**100倍**。电力时代的工厂建设则需要更大规模的资本投入。如此高昂的成本，远非单个发明家或工厂主所能承受。

#### 【金融变革】

- 第一次工业革命 → **现代商业银行**：将农村储蓄转化为工业信贷
- 第二次工业革命 → **现代投资银行**：通过股票承销、并购顾问为大规模产业整合提供资本

#### 【案例】瓦特与摩根：技术需要资本的两个版本

**版本一（第一次工业革命）** ：詹姆斯·瓦特在改良蒸汽机过程中负债1000英镑，濒临破产。他的投资人博尔顿持续注资才让蒸汽机走出实验室。英国央行2011年版50英镑纸钞上印着瓦特和博尔顿的肖像——**技术家与资本家的双人像**，本身就是科技-金融共生的象征。

**版本二（第二次工业革命）** ：J.P.摩根对爱迪生投资**1000万美元**，合伙创立爱迪生电灯公司。华尔街曾说：“如果说上帝创造了世界，那么摩根重组了世界。”

### 3.3 第三次工业革命：信息技术与风险投资

#### 【核心技术演进】

- 晶体管（1947）→ 集成电路（1958）→ 微处理器（1971）→ 个人电脑（1980s）→ 互联网（1990s）

这条技术链是**计算机科学**的核心叙事。

#### 【金融变革】

第三次工业革命催生了**风险投资（VC）、私募股权（PE）** 等新金融业态。

#### 【案例】硅谷沙山路：风险投资的集聚地

1972年，KPCB和红杉资本在硅谷沙山路成立。**几乎每家硅谷顶级公司都受益于沙山路提供的资金**——从苹果、微软到谷歌、Facebook。VC体系为信息技术产业提供了创始资本。

### 3.4 历史规律：技术-金融“双螺旋”

纵观三次工业革命，一条清晰的规律浮现：

> **技术创造可能，金融实现可能。二者不是谁依附谁，而是“双螺旋”式的共生演进。**

每一次工业革命对应着一次金融革命：

| 工业革命 | 金融革命 |
|---------|---------|
| 第一次工业革命 | **现代商业银行** |
| 第二次工业革命 | **现代投资银行** |
| 第三次工业革命 | **创业投资体系** |

当前，**第四次工业革命**正在发生。世界经济论坛创始人施瓦布指出，这次革命的特点是**技术融合**——模糊了实体、数字和生物世界的界限，**以指数级而非线性速度展开**，几乎“打破了每个国家每种行业的发展模式”。

第四次产业技术革命定性为“**智能化革命**”，特点是“**全方位创新**”“**系统性、整体性**”“**全面渗透、跨界应用**”。**数、算、智成为“新引擎”**。

第四次产业革命对融资有全新需求——AI产业**资本支出巨大，未来收益高度不确定**——这恰恰呼唤着全新的金融形态。

**关键认识**：**我们正在亲历的，不仅是技术的迭代，更是一次工业革命与金融革命同时发生的历史性交汇**。


## 四、金融科技（FinTech）：从概念到浪潮

### 4.1 什么是金融科技？

金融科技（FinTech），广义上指技术驱动的金融创新。但更准确地说，是技术与金融业务逻辑的深度融合——技术嵌入到金融产品设计、风险定价、客户交互、交易执行的全链条。

### 4.2 金融科技的发展阶段

| 阶段 | 特征 | 代表 |
|------|------|------|
| **FinTech 1.0**（金融信息化） | 技术作为后台工具 | 会计电算化、柜台系统 |
| **FinTech 2.0**（互联网金融） | 技术作为渠道 | 网上银行、移动支付 |
| **FinTech 3.0**（智能金融） | 技术嵌入业务核心 | AI风控、智能投顾 |

当前我们正处在FinTech 2.0向3.0的深度演进中。麦肯锡判断金融科技的核心不再是速度和便利，而是**对金融体系的重构**。

#### 【技术拆解】这些数字背后的技术含义是什么？

**1. Token消耗量意味着什么？**

Token是大模型处理文本的基本单位。日均Token消耗量从两年前的“几乎为零”到今天的“百亿级”，反映的是**AI从“试点探索”走向“生产系统”** 的质变。Token消耗量相当于AI时代的“用电量”——它衡量的是AI能力被实际调用的强度。

**2. 推理成本下降87%意味着什么？**

邮储银行模型上线周期从2周缩短到1天，缓存占用下降72%，推理成本最高节省87%。这反映了**大模型工程优化**（模型量化、缓存策略、蒸馏等）的快速进步——成本曲线下降的速度决定了AI应用扩散的速度。

**3. 千卡规模AI算力云意味着什么？**

工行建成同业首个**自主可控的千卡规模AI算力云**，具备TB级数据、千亿大模型全参二次训练能力。“千卡”指GPU数量——这是衡量机构AI算力基础设施规模的核心指标。工行能够对千亿参数大模型进行“全参二次训练”（而非仅仅微调），意味着银行已具备**从头调整大模型核心能力**的技术实力，这在金融行业中处于领先地位。

#### 【典型案例一】工商银行：“工银智涌”的技术架构与规模化落地

工行“工银智涌”体系集成**十余个大模型与两千多个传统模型**的协同矩阵。技术上，这套体系的核心能力在于：

- **模型路由**：根据任务类型自动选择最合适的模型（简单任务→小模型，复杂推理→大模型），实现成本与效果的平衡
- **私有化部署**：率先完成DeepSeek最新开源大模型的私有化部署——数据不出行，满足金融合规要求
- **全参训练能力**：基于千卡算力云，具备对千亿大模型进行全参数二次训练的能力

**业务效果**：个人客户经理方案匹配从1小时缩短至**2-3分钟**；远程银行通话时长压降10%；金融市场智能询价交易占比突破96%。

#### 【典型案例二】建设银行：“AI+风控”的技术逻辑

建行山东省分行案例中，“科创雷达”与“帮得”AI助理组合发挥作用。

**技术拆解**：

- “科创雷达”本质是一个**知识图谱系统**——集成了数千万家工商企业及千万级知识产权数据，构建了企业与专利、产业链之间的关联网络
- “帮得”AI助理基于**大语言模型**，具备自然语言交互和信息抽取能力，能将非结构化的企业信息转化为结构化的“科技画像”
- 两者的结合实际上是一个**RAG（检索增强生成）** 架构——从知识图谱检索信息，再由大模型生成分析

**业务效果**：企业技术实力变得可量化、可评估，**无需抵押物**即可获得贷款。客户经理**1秒**即可显示目标客户清单。

### 5.5 智能体（Agent）：2026年的核心技术叙事

#### 【技术背景】什么是智能体？

智能体（Agent）是以大模型为**认知引擎**，能理解目标、拆解任务、调用工具并自主完成工作的系统。

**技术架构**：

| 模块 | 功能 |
|------|------|
| **感知模块** | 理解用户意图和环境信息 |
| **规划模块** | 将复杂目标分解为子任务 |
| **执行模块** | 调用工具（API、数据库、软件等）完成任务 |
| **记忆模块** | 存储历史交互和任务状态 |

**为什么2026年是“智能体元年”？** 大模型在2023—2024年主要完成的是“对话能力”的突破，但单纯的对话无法直接替代金融业务中的复杂工作流程。智能体将“理解”转化为“行动”——这是AI从“能聊”到“能干”的关键跨越。

#### 【各银行实践】

| 银行 | 智能体实践 |
|------|-----------|
| **招商银行** | 拆分出多类细分智能体，财富投研小助、火眼尽调智能体等 |
| **宁波银行** | 财务大模型AI智审智能体——识别合同、差旅单，自动校验、标记异常 |
| **微众银行** | **80多位数字员工“入职”**，7×24小时在线，研发数字员工效率提升**超10倍** |

2026年1—6月，金融智能体公开招标**97条**，覆盖10多类持牌金融机构。

**但需注意**：农业银行董事长谷澍在陆家嘴论坛上指出，各家银行对“智能体”的统计口径各行其是——“有的几百个，有的上万个”。智能体建设尚未形成统一范式，行业仍面临 **“有量无尺”的困境**。这正是金融从业者需要具备技术判断力的原因。

## 六、技术视角：AI能做什么与不能做什么——从技术原理出发

本课程希望为同学们建立一个重要的认知框架：**理解AI的真实能力边界**。

### 6.1 大语言模型的能力来源：从技术原理说起

大语言模型（LLM）如GPT、DeepSeek等，其核心技术是**Transformer架构**。简单理解：

- 传统计算机程序是“如果A则B”的规则系统——只能处理预先编程的场景
- 大模型本质上是一个**超大规模的统计模型**，通过分析海量文本中的模式，学会了“在给定上下文中，下一个词最可能是什么”

这意味着：

| 大模型擅长 | 大模型不擅长 |
|-----------|-------------|
| 模式识别 | 精确计算 |
| 文本生成 | 逻辑推理的一致性 |
| 信息整合 | 对未见过的场景的可靠判断 |
| 自然语言交互 | — |

**金融启示**：大模型适合做“辅助决策”和“信息处理”，但不应被信任做“精确判断”和“自主交易”——至少目前如此。

### 6.2 AI的幻觉问题：技术根源与金融风险

“幻觉”（Hallucination）指AI生成看似合理但实际错误的内容。从技术上讲，这是因为大模型是**概率生成模型**——它生成的是“最可能”的词序列，而不是“经过验证正确”的事实。

**对金融业的影响**：

- 在研报生成中，AI可能编造不存在的财务数据
- 在风控场景中，AI可能基于不存在的“事实”做出风险评估
- 在合规审查中，AI可能引用不存在的法规条款

**解决方向**：

| 方法 | 说明 |
|------|------|
| **RAG（检索增强生成）** | 让AI先检索知识库再生成答案，而不是完全依赖模型内部“记忆” |
| **事实核查层** | 在AI生成内容后增加验证环节 |
| **人类在环（Human-in-the-loop）** | 关键决策必须有人类确认 |

### 6.3 可解释性（XAI）：为什么AI做出某个决策

在金融风控和信贷审批中，监管要求决策必须有可解释的理由。但深度学习模型是典型的 **“黑箱”**——输入数据经过数百万个参数的计算后输出结果，连开发者都难以说清“为什么”得到这个结果。

**当前技术进展**：

| 方法 | 原理 |
|------|------|
| **LIME/SHAP** | 通过扰动输入观察输出变化，推断哪些特征对决策影响最大 |
| **注意力可视化** | 展示模型在做出决策时“关注”了输入中的哪些部分 |
| **反事实解释** | “如果收入提高10%，结果会从拒绝变为批准” |

**金融启示**：AI可解释性技术的成熟度**远低于**AI预测能力。在监管要求明确之前，完全自动化的AI信贷审批需要谨慎对待。

可解释性是建立信任的基础，但大模型的可解释性是个技术悖论。
